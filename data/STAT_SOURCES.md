# Stratagem stat sources

Data checked 2026-10-07 UTC. `stats-source.json` has one entry for each of the 109 stratagem tiles in the supplied desk-mat layout. IDs match the eight category JSON files. The arrow code, base cooldown, cost, unlock source, and available support-weapon damage/capacity/fire-rate/armor-penetration data were transcribed from [DiversHub's stratagem catalog](https://divershub.app/database/stratagems) and each item's linked detail page. Each entry retains its detail URL.

DiversHub credits the [Helldivers Wiki](https://helldivers.wiki.gg/wiki/Stratagems) under CC BY-NC-SA 4.0 and the Fandom wiki under CC BY-NC-SA. Numeric game facts are included here; its prose descriptions are not copied. Credits and links should remain visible on the site. The [MIT-licensed JSON generator](https://github.com/k33bs/Helldivers-2-Stratagem-JSON-Generator) independently records 110 input sequences and credits the supplied nvigneux SVG icons.

The live catalog lists 111 entries. The desk mat has 109: the additional catalog entries are Reinforcement Pods and SSSD Delivery. They were excluded to preserve the user-provided layout.

`stats-source.json` is a baseline, not an assertion that all its figures are authoritative. `verified-overrides.json` contains more specific, recent wiki/official-patch corrections and should win when fields conflict (notably Orbital Precision Strike, 40-K Meltagun, and Exosuit cooldowns). The game can modify cooldown/call-in values through ship upgrades, mission modifiers, or temporary campaign effects. Show these as base values. Limited uses and call-in time are omitted when the source did not publish a reliable value; do not turn missing fields into zero or "unlimited." Weapon damage is a labeled list in some cases because projectile, explosive, and other damage components differ.

Quality check: all 109 entries have nonempty arrow codes. All 16 mission-command codes were checked against the independent generator, with Orbital Illumination Flare resolved against the current wiki page. Across all 109 codes, the only generator discrepancies were Cremator, TD-110 Maelstrom, and Illumination Flare; current wiki pages confirm the corrected codes saved here. Illumination Flare has no current cooldown and was removed from the actual Stratagem Hero in 2024, so it should remain a reference tile but be excluded from an authentic game pool. The generator's historical six-arrow flare code is obsolete.
